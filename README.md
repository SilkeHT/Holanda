# Holanda

Web universidad holanda: **Llegando a Holanda**, una guía en español para estudiantes que van a estudiar a una universidad de los Países Bajos.

Es una web estática (HTML, CSS y un poco de JavaScript), sin dependencias ni proceso de compilación.

- `index.html`: página de inicio (casas de canal, índice de temas y "Quién está detrás").
- Una página por tema: `llegada.html`, `alojamiento.html`, `ciudades.html`, `presupuesto.html`, `beca-duo.html`, `trabajo.html`, `neerlandes.html`, `bici-y-tren.html`, `seguro.html`, `comunidad.html` y `preguntas.html`.
- `css/styles.css`: estilos y paleta de colores (compartidos por todas las páginas).
- `js/main.js`: menú en móvil y calculadora de presupuesto.

El menú y el pie de página están repetidos en cada página: si cambias uno, cámbialo en todas.

Para verla, abre `index.html` en el navegador. Se publica con GitHub Pages desde la rama `main`.

Las cifras (salario mínimo, beca DUO, seguro médico) están revisadas en noviembre de 2026; conviene actualizarlas cada año.
