# Holanda

Web universidad holanda: **Llegando a Holanda**, una guía en español para estudiantes que van a estudiar a una universidad de los Países Bajos.

Es una web estática (HTML, CSS y un poco de JavaScript), sin dependencias ni proceso de compilación.

- `index.html`: todo el contenido de la página.
- `css/styles.css`: estilos y paleta de colores.
- `js/main.js`: menú en móvil.

Para verla, abre `index.html` en el navegador. Para publicarla gratis, activa GitHub Pages en la rama principal.

Las cifras (salario mínimo, beca DUO, seguro médico) están revisadas en noviembre de 2026; conviene actualizarlas cada año.
